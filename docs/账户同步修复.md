# 0.1.2 账户同步与个人入口

- 修复 Cookie 中间项前有空白时漏识别 z_c0 的错误。
- WebView 页面完成登录自动加密保存 Cookie，普通返回和关闭页先保存再清理浏览器 Cookie。
- 恢复网页登录时等待 CookieManager 设置完成再 loadUrl，避免首次请求未携带会话。
- 首次启动尝试恢复之前已存在的网页登录会话，无需重新登录。
- 通过真实 /api/v4/me 同步头像、昵称、简介和账户数值；资料缓存 AES-GCM 加密。
- 增加我的赞同、收到的评论与回复、私信列表与只读会话页面。
- 账户历史使用服务端分页；赞同源为账户动态，提示其历史覆盖限制。
- 私信只 GET，不发送或回复，不主动标记已读；撤回消息不展示原文本，复杂媒体提供官方原会话入口。
- 账户 API 与 UI 数据不写磁盘响应缓存，调试记录只输出布尔值、HTTP 状态和计数。

真实设备会话检查：保存成功、资料同步成功、头像存在、会话恢复成功、加密资料缓存成功；赞同 4 条、收到评论通知 1 条、私信会话列表 20 条、首个会话消息 20 条。数字来自本次实测，不代表全部历史，也没有硬编码进入产品。

设备验收记录见 account-endpoints.txt 和 account-ui-check.json。最终 release 在真实设备通过头像恢复、赞同列表、评论与回复、私信列表与会话页面检查。姓名、Cookie 和消息正文未输出到工具日志。0.1.2 release 构建和 lintDebug 已通过。
